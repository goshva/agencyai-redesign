Существующие URL Хронология Git, Хронология Гант, переписка и модель процесса уже отражены в текущей demo-архитектуре. Эти макеты обновляют их визуальную подачу, но не меняют логику и маршруты.
Предлагаемые URL Обзор, список обращений и карточка — целевые новые экраны. Их маршруты ещё нужно сверить и согласовать на Этапе 0; не считать их существующими.
Как использовать Откройте HTML в браузере. Для проверки используйте ширины 1440, 1024, 768 и 390 px. Сравнивайте композицию и поведение, а не буквальное совпадение всех пикселей.
Ограничение данных Демонстрационные номера, роли, SLA, тексты и показатели нужны только для заполнения макета. Рабочая реализация обязана читать данные из `src/core` и `src/data` и не выдумывать отсутствующие поля.
